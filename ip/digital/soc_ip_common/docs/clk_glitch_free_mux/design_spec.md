# clk_glitch_free_mux Design Specification

## 1. 概述

`clk_glitch_free_mux` 是一个无毛刺的 2 选 1 时钟多路复用器（Glitch-Free 2-to-1 Clock Multiplexer），用于在两个异步时钟源之间进行安全切换，确保输出时钟不会产生毛刺（glitch）或短脉冲（runt pulse）。

**版本: 3.3** — 基于标准单元库实现：std_cell_sync + std_cell_icg + std_cell_clk_or。

该模块属于时钟生成（clk_gen）类别，是 SoC 时钟管理单元的关键组件，常用于：

- 时钟源切换（如从内部振荡器切换到外部晶振）
- 低功耗模式下的时钟门控
- 测试模式时钟选择

## 2. 功能描述

### 2.1 核心功能

| 功能         | 描述                                   |
| ---------- | ------------------------------------ |
| 2 选 1 时钟选择 | 通过 `sel` 信号选择 `clk0` 或 `clk1` 输出     |
| 异步复位       | `rst_n` 为低时，同步器清零，输出时钟关闭             |
| 测试模式       | `test_mode` 为高时，ICG 强制透传时钟（DFT scan） |
| 无毛刺切换      | 使用反馈互锁 + 同步器 + ICG 确保切换时不会产生毛刺       |
| 异步时钟支持     | `clk0` 和 `clk1` 可为完全异步的时钟源           |
| 异步 sel 安全  | `sel` 可在任意时刻异步翻转，互锁机制保证安全            |

### 2.2 真值表

| rst_n | sel | test_mode | clk_out      | 说明                          |
| ----- | --- | --------- | ------------ | --------------------------- |
| 0     | X   | X         | 0            | 复位状态，输出恒低                   |
| 1     | 0   | 0         | clk0 (gated) | 选择时钟源 0，ICG 受 en0_sync 控制   |
| 1     | 1   | 0         | clk1 (gated) | 选择时钟源 1，ICG 受 en1_sync 控制   |
| 1     | X   | 1         | 选中时钟透传       | test_mode=1 时 ICG 强制使能（DFT） |

### 2.4 工作原理

1. **反馈互锁（break-before-make）**：
   
   - `en0_raw = ~sel & ~en1_sync`
   - `en1_raw = sel & ~en0_sync`
   - 新时钟的使能只能在旧时钟的同步使能完全关闭后才能置高

2. **跨时钟域同步**：
   
   - `std_cell_sync`（2-stage）将 `en0_raw` 同步到 `clk0` 域，产生 `en0_sync`
   - `std_cell_sync`（2-stage）将 `en1_raw` 同步到 `clk1` 域，产生 `en1_sync`
   - 同步器带 `rst_n` 异步复位，低电平有效

3. **时钟门控**：
   
   - `std_cell_icg` 根据 `en0_sync` / `en1_sync` 对 `clk0` / `clk1` 进行门控
   - `test_mode` 连接到 ICG 的 `test_en`，DFT 扫描时强制透传时钟

4. **时钟合并**：
   
   - `std_cell_clk_or` 将两路 gated 时钟合并为 `clk_out`
   - `std_cell_clk_or` 为时钟路径专用 OR 门，比普通 `std_cell_or` 具有更好的时钟特性（更对称的上升/下降延时、更低的数据依赖抖动）

**无毛刺保证**：

- **反馈互锁**：即使 `sel` 是异步信号且在任何时刻翻转，互锁逻辑确保两个时钟源不会同时被使能
- **同步器延时**：2-stage 同步器引入约 2 个目标时钟周期的延时，确保互锁状态稳定传播
- ICG 在使能信号稳定后才打开时钟，不会在时钟高电平期间产生截断脉冲
- 切换过程中，旧时钟先被关闭（在其低电平期），新时钟后在低电平期被使能，两个 gated 时钟不会同时为高

## 4. 设计要点

### 4.1 关键设计决策

| 决策项  | 选择                           | 理由                                                      |
| ---- | ---------------------------- | ------------------------------------------------------- |
| 同步方案 | std_cell_sync（2-stage）       | 标准单元实现，带 async reset，可复用、可替换为 metastability-hardened 版本 |
| 时钟门控 | std_cell_icg                 | 标准 ICG 单元，集成 latch + AND，面积小、时序清晰、支持 test_en            |
| 输出合并 | std_cell_clk_or              | 时钟路径专用 OR 门（v3.3），比普通 OR 门有更对称的上升/下降延时，降低数据依赖抖动         |
| 反馈互锁 | `en0_raw = ~sel & ~en1_sync` | 支持异步 sel 输入，确保 break-before-make，防止两个时钟同时使能             |
| 复位策略 | `rst_n` 接入同步器 async reset    | v3.1 新增，确保上电/复位时输出确定性地为低                                |
| 测试模式 | `test_mode` 接入 ICG test_en   | 支持 DFT 扫描，test_mode=1 时 ICG 强制透传                        |

### 4.2 版本演进历史

| 版本       | 变更内容                                                                    |
| -------- | ----------------------------------------------------------------------- |
| v1.0     | 手写的 latch + AND 门实现                                                     |
| v2.0     | 新增反馈互锁（feedback interlock），支持异步 sel 安全切换                                |
| v3.0     | 重构为 std_cell_sync + std_cell_icg 标准单元架构                                 |
| v3.1     | 移除 `clk_en` 端口，新增 `rst_n` 端口（同步器异步复位）                                   |
| v3.2     | 移除冗余 sel0/sel1 中间 wire，直接使用 `~sel` 和 `sel`；使用 `std_cell_or` 合并 gated 时钟 |
| **v3.3** | **将 `std_cell_or` 替换为 `std_cell_clk_or`（时钟路径专用 OR 门），优化时钟特性**           |

### 4.3 传播延时估计

- **clk0/clk1 -> clk_out 路径**：~1.0 ns（ICG 延时 + std_cell_clk_or 延时）
- **sel -> clk_out 路径**：需等待对应时钟域 2-stage sync（~2 个目标时钟周期）+ ICG 使能延时
- **rst_n -> clk_out 路径**：异步复位立即生效（同步器 async reset），输出在复位释放后经 2-stage sync 恢复

### 4.4 面积与单元清单

| 单元类型            | 数量        | 说明                                          |
| --------------- | --------- | ------------------------------------------- |
| std_cell_sync   | 2         | 2-stage bit synchronizer，分别同步到 clk0/clk1 域  |
| std_cell_icg    | 2         | 标准 ICG 单元，分别门控 clk0/clk1                    |
| std_cell_clk_or | 1         | 时钟路径专用 OR 门（v3.3）                           |
| NOT 门           | 2         | `~sel`、`~en1_sync` / `~en0_sync`（由互锁逻辑隐式使用） |
| **总计标准单元**      | **5 个实例** | 高度可复用的标准单元架构                                |

### 4.5 DFT / 物理实现注意事项

1. **std_cell_sync**：需确保同步器的 DFF 在物理上靠近对应时钟域的 ICG 放置，减少时钟偏斜
2. **std_cell_icg**：ICG 中的 latch 是 glitch-free 机制的核心，需标记 `set_dont_touch`，防止综合工具优化掉
3. **std_cell_clk_or**：时钟路径 OR 门应放置在时钟树根部附近，避免长连线导致的 clock latency 差异
4. **时钟树综合**：`clk_out` 需接入时钟树综合（CTS）
5. **STA 分析**：真实时序分析需在 SoC 层级进行，分别对 `clk0` 和 `clk1` 路径进行时序分析
6. **DFT**：`test_mode` 信号在扫描测试时置高，确保 ICG 透传时钟，不影响 scan chain 的时钟传播

## 5. 验证要点

- 基本 2 选 1 功能正确性
- 复位功能（rst_n 低电平时输出恒低，释放后正常恢复）
- 切换过程无毛刺（runt pulse 检测）
- 异步时钟源切换
- 快速 sel 翻转下的稳定性
- 多次来回切换的可靠性
- test_mode 功能（DFT 扫描时 ICG 透传）

## 6. 综合约束

- **max_delay**: 2.0 ns（从 clk0/clk1 到 clk_out）
- **set_dont_touch**: 对 std_cell_icg 中的 latch 单元
- **时钟定义**: `clk0`、`clk1` 需分别定义时钟约束，标记为 logically exclusive
- **WNS**: 需满足目标工艺库要求（TIMING MET）

## 7. 状态机

无。本模块为同步器 + ICG + 组合逻辑结构，无时序状态机。
