# opentitan_alert_handler

OpenTitan native RTL ownership package for vibe_soc. Source files referenced by this package filelist have been promoted under `de/rtl/src/` from the chip-level OpenTitan vendor island. The original vendor tree is retained as upstream reference collateral.

This package is currently validated at chip level: `chip_earlgrey_asic` compile and `chip_sw_uart_smoketest`. Standalone module DV can be added after a package-specific interface document is approved.
