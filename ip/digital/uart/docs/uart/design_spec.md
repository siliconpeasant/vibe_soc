# uart Design Spec

## 1. 概述

本文档描述 vibe_soc 项目中 UART (Universal Asynchronous Receiver/Transmitter) IP 的设计规格。该模块提供全双工串行通信功能，支持经典的 8N1 帧格式（1 start bit + 8 data bits + 1 stop bit，无奇偶校验），并可通过可编程波特率分频器适配多种通信速率。

## 2. 功能描述

### 2.1 顶层功能

- **TX (发送器)**：将并行 8-bit 数据转换为串行比特流输出，帧格式为 8N1
- **RX (接收器)**：从串行输入线接收 8N1 帧数据，转换为并行 8-bit 输出
- **波特率生成器**：基于系统时钟和可配置分频系数产生波特率 tick，驱动 TX/RX 时序
- **过采样接收**：RX 采用 16x 过采样，在每位中心点采样以提高抗噪能力

### 2.2 帧格式 (8N1)

```
Idle    Start   D0      D1      D2      D3      D4      D5      D6      D7      Stop    Idle
HIGH    LOW     LSB                                    MSB     HIGH
```

- Start bit：1 个 bit 时间低电平
- Data bits：8 个 bit 时间，LSB first
- Stop bit：1 个 bit 时间高电平
- 无奇偶校验位

### 2.3 波特率支持

系统时钟 100MHz 时，常用波特率对应的分频值：

| 波特率 | 分频值 (100MHz / 波特率 / 16) | 实际波特率 | 误差 |
|--------|-------------------------------|------------|------|
| 9600   | 651 (0x28B)                   | 9601.5     | +0.016% |
| 19200  | 326 (0x146)                   | 19171.8    | -0.15% |
| 38400  | 163 (0xA3)                    | 38343.6    | -0.15% |
| 57600  | 109 (0x6D)                    | 57339.4    | -0.45% |
| 115200 | 54 (0x36)                     | 115740.7   | +0.47% |

分频公式：`baud_div = round(clk_freq / baud_rate / 16) - 1`

## 4. 子模块详细设计

### 4.1 Baud Rate Generator (波特率生成器)

- 输入：`clk`, `rst_n`, `baud_div[15:0]`
- 输出：`baud_tick`
- 功能：对系统时钟进行分频，每 `baud_div + 1` 个时钟周期产生一个 `baud_tick` 脉冲
- 实现：一个 16-bit 计数器，计数到 `baud_div` 时回零并产生 tick
- TX 直接使用 `baud_tick` 作为位时钟；RX 使用 16x 过采样，因此 RX 侧计数器以 `baud_tick` 的 16 倍频运行（或直接以系统时钟分频到 `baud_tick * 16`）

**实现方案**：产生一个 `sample_tick`（16x 过采样时钟），即每 `div16 = round(clk_freq / baud_rate / 16)` 个系统时钟产生一个 tick。TX 使用每 16 个 `sample_tick` 作为一位时间；RX 直接使用 `sample_tick` 进行采样。

更简洁的方案：产生 `baud_tick`（每位一个 tick），RX 内部再维护一个 4-bit 计数器（0~15）在 `baud_tick` 基础上做 16 细分。为简化设计，采用以下方案：

- 波特率分频器产生 `baud_tick`（每位周期一个脉冲）
- RX 模块内部使用 `clk` 直接过采样，维护独立的 `rx_div_cnt` 计数器，以 `baud_div/16` 为步进做 16x 采样

**最终方案**：统一使用 `baud_div` 作为系统时钟到波特率 tick 的分频值。RX 在检测到 start bit 后，等待 `baud_div * 8` 个时钟（半位时间）进行首次确认采样，之后每隔 `baud_div * 16` 个时钟采样一位中心点。TX 每隔 `baud_div * 16` 个时钟发送一位。

### 4.2 TX Controller (发送控制器)

**状态机**：

```
+--------+    tx_valid & tx_ready    +-------+
|  IDLE  |-------------------------->| LOAD  |
|        |<--------------------------|       |
+--------+    tx_done (auto)         +-------+
    ^                                      |
    |                                      | load data
    |                                      v
    |                                 +--------+
    +---------------------------------| SHIFT  |
         tx_bit_cnt == 10 (done)      |        |
                                      +--------+
```

**状态定义**：

| 状态 | 编码 | 描述 |
|------|------|------|
| TX_IDLE  | 2'b00 | 空闲，tx_out = 1，等待 tx_valid |
| TX_START | 2'b01 | 发送 start bit (0) |
| TX_DATA  | 2'b10 | 发送 8 data bits |
| TX_STOP  | 2'b11 | 发送 stop bit (1) |

**数据通路**：
- `tx_shift_reg[9:0]`：{stop_bit(1), data[7:0], start_bit(0)}，从 LSB 开始移出
- `tx_bit_cnt[3:0]`：已发送 bit 计数（0~9）
- `tx_baud_cnt`：波特率周期计数器

**时序**：
- `tx_ready`：TX_IDLE 状态时为 1，表示可接收新数据
- `tx_busy`：非 TX_IDLE 状态时为 1
- `tx_done`：TX_STOP 状态结束且 baud_cnt 匹配时产生一个时钟周期的高电平脉冲

### 4.3 RX Controller (接收控制器)

**过采样与采样策略**：
- 使用 16x 过采样：每位时间被分为 16 个采样点
- Start bit 检测：检测 `rx_in` 下降沿（从 1 到 0）
- Start bit 确认：在检测到下降沿后，等待 8 个采样周期（半位时间），再次采样确认仍为低电平，排除毛刺
- Data bit 采样：在每位中心点（第 8 个采样点，即 start 确认后再过 16 个采样周期）采样

**状态机**：

```
+--------+   rx_in == 0 (falling edge)   +--------+
|  IDLE  |------------------------------>| START  |
|        |                               | (confirm|
+--------+                               |  at 1/2)|
    ^                                    +--------+
    |                                          |
    |                                          | confirmed low
    |                                          v
    |                                    +--------+
    +------------------------------------|  DATA  |
         rx_bit_cnt == 8 (done)          | (sample|
                                         |  center)|
                                         +--------+
                                               |
                                               | 8 bits done
                                               v
                                         +--------+
                                         |  STOP  |
                                         | (check |
                                         |  high)  |
                                         +--------+
```

**状态定义**：

| 状态 | 编码 | 描述 |
|------|------|------|
| RX_IDLE  | 3'b000 | 空闲，等待 start bit 下降沿 |
| RX_START | 3'b001 | 检测到下降沿，等待半位时间确认 |
| RX_DATA  | 3'b010 | 接收 8 data bits |
| RX_STOP  | 3'b011 | 接收 stop bit，检查 framing error |
| RX_DONE  | 3'b100 | 接收完成，输出数据并返回 IDLE |

**数据通路**：
- `rx_shift_reg[7:0]`：从 LSB 开始移入采样值
- `rx_bit_cnt[3:0]`：已接收 bit 计数（0~7）
- `rx_sample_cnt`：过采样计数器（0~15）
- `rx_in_sync[1:0]`：rx_in 两级同步器，消除亚稳态

**时序**：
- `rx_valid`：RX_DONE 状态时产生一个时钟周期的高电平脉冲
- `rx_busy`：非 RX_IDLE 状态时为 1
- `rx_frame_err`：RX_STOP 状态采样到 stop bit 为 0 时置 1，与 `rx_valid` 同时有效

## 6. 设计要点

### 6.1 关键假设

1. **系统时钟**：默认 100MHz，通过 `baud_div` 参数化支持其他频率
2. **复位策略**：`rst_n` 为异步 assert、同步 deassert（或纯同步复位），确保跨时钟域安全
3. **无 FIFO**：单字节缓冲，TX/RX 各只有一个数据寄存器
4. **无奇偶校验**：8N1 格式，简化设计
5. **RX 输入同步**：`rx_in` 经过两级 DFF 同步，消除亚稳态
6. **波特率误差容忍**：±2% 以内可正常通信（UART 标准通常允许 ±3%）

### 6.2 面积与延时估计

- 预估门数：~500 等效门（不含 IO pad）
- TX 关键路径：`baud_cnt` 比较 → `tx_shift_reg` 移位 → `tx_out`，纯组合逻辑，单周期完成
- RX 关键路径：`rx_in_sync` → 状态机判断 → `rx_shift_reg` 写入，单周期完成
- 最高系统时钟：取决于工艺，100MHz 在 28nm 以下无压力

### 6.3 低功耗考虑

- 模块本身无时钟门控（ICG），由上层 SoC 控制 `clk` 使能
- TX 空闲时保持 `tx_out = 1`，无动态翻转
- RX 持续采样 `rx_in`，若需低功耗可在外部关闭 `clk`

## 7. 验证要点

- 各波特率下的 TX/RX 回环测试（9600 ~ 115200）
- 边界波特率（最小/最大分频值）
- RX 过采样正确性（start bit 毛刺过滤、数据位中心采样）
- Framing error 检测（stop bit 为 0）
- 连续发送/接收（背靠背传输）
- 复位后状态正确性

## 8. 综合约束

- 目标频率：100MHz（`create_clock -period 10 [get_ports clk]`）
- 输入延迟：`set_input_delay -clock clk 2.0 [get_ports {rx_in baud_div[*]}]`
- 输出延迟：`set_output_delay -clock clk 2.0 [get_ports {tx_out rx_data[*] rx_valid rx_busy rx_frame_err}]`
- 异步输入：`set_false_path -from [get_ports rst_n]`（若采用异步复位）
- `tx_out` 和 `rx_in` 为外部 IO，需约束驱动强度/负载

## 9. 状态机

### 9.1 TX 状态机 (4 状态)

```
         +---------+
         | TX_IDLE |<---------------------------+
         +---------+                            |
              | tx_valid & tx_ready             |
              v                                 |
         +----------+     baud_tick             |
         | TX_START |-------------------------->|
         +----------+                            |
              | baud_tick                       |
              v                                 |
         +---------+     bit_cnt < 8            |
    +--->| TX_DATA |--------------------------->|
    |    +---------+                            |
    |         | bit_cnt == 8 & baud_tick        |
    |         v                                 |
    |    +---------+     baud_tick              |
    +----| TX_STOP |--------------------------->|
         +---------+
```

### 9.2 RX 状态机 (5 状态)

```
         +---------+
         | RX_IDLE |<---------------------------+
         +---------+                            |
              | rx_in_sync == 0 (falling edge)  |
              v                                 |
         +----------+     sample_cnt == 8       |
         | RX_START |-------------------------->|
         +----------+     & rx_in_sync == 0     |
              | (else return IDLE if high)      |
              v                                 |
         +---------+     bit_cnt < 8            |
    +--->| RX_DATA |--------------------------->|
    |    +---------+                            |
    |         | bit_cnt == 8 & sample done      |
    |         v                                 |
    |    +---------+                            |
    +----| RX_STOP |--------------------------->|
         +---------+
```
