# uart Register Map

## 概述

本 UART 模块为纯端口配置型设计，不含有内部可寻址寄存器。波特率分频系数通过顶层端口 `baud_div[15:0]` 直接输入，由外部逻辑（如 SoC 配置总线或固定参数）驱动。

## 寄存器列表

无。

## 配置说明

| 配置项 | 端口/参数 | 位宽 | 默认值 | 说明 |
|--------|-----------|------|--------|------|
| 波特率分频 | `baud_div` | 16 | 外部输入 | `(clk_freq / baud_rate / 16) - 1`，见 design_spec.md 常用值表 |

## 备注

- 若未来集成到 SoC 总线（如 APB），可在此增加 `BAUD_DIV` 寄存器（offset 0x00，RW）
- 若未来增加 FIFO，可在此增加 `TX_FIFO` / `RX_FIFO` 数据寄存器和状态寄存器
